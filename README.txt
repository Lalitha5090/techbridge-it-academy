## Preview locally
Open `index.html` in a browser. For best results, serve the folder using a static web server.

## Publish online
You need a hosting provider and a registered domain. This package is static HTML/CSS/JS and can be hosted on GitHub Pages, Netlify, Cloudflare Pages or another static hosting provider.
1. Extract the ZIP.
2. Upload the contents of this folder (not the ZIP itself) to your hosting provider.
3. Set `index.html` as the entry page (default on common static hosts).
4. Connect your registered domain through the host's domain settings.
5. Follow the DNS records provided by your hosting provider.

The domain `techbridgeacademy.in` has not been purchased or verified by this package.

## Important form behavior
The enquiry forms do not store data in a database or send email automatically. They validate the fields and open WhatsApp with a pre-filled message. The visitor must press Send in WhatsApp. For automated lead storage/email notifications, connect a form backend or CRM later.

## Accuracy and placement claims
The website describes placement assistance, interview preparation and job-search guidance. It does not promise guaranteed employment or claim unverified recruiter partnerships.
